## 🧭 How this repo works

- **Vibecoded** means the code was generated by AI from my prompts. I decided what to build, how it should behave and what got changed, and I tested and used it, but I didn't type most of the code.
- Each project is a **self-contained folder** with its own README, install steps and caveats.
- Treat everything here as a working prototype, not production software.
- Personal data is stripped before anything is published.
