### Install everything

Download this repo and double-click **`install-all.command`**. It fetches the twelve repos and runs each one's installer. Want just one? Open its repo and use its own `install.command`.

```
  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ OUTPOST//│ │PONG//SOLO│ │NOTE//PAD │ │WALLET//Ð │
  │          │ │          │ │          │ ├──────────┤
  │          │ │          │ │          │ │ 75//HARD │
  └──────────┘ ├──────────┤ ├──────────┤ │          │
               │2048//TILE│ │ TETRIS   │ ├──────────┤
               │          │ │  //GRID  │ │STUDY/TERM│
               │          │ │          │ ├──────────┤
               └──────────┘ └──────────┘ │QUOTE//DAY│
                                         └──────────┘
```
<sub>Default layout. Rearrange or hide widgets in WIDGET//CTL (`⌃⌥⌘S`).</sub>

### How they're built

- Each widget is React/JSX running in Übersicht. The ones that store data shell out to a small **stdlib-only Python** backend: no dependencies, no server.
- Data lives in `~/Library/Application Support/STUDYTERM/`: atomic writes, file locks, plain JSON and CSV you can open yourself.
- The wallet, 75 Hard and study timer started life inside my **Obsidian** vault. Each repo ships a standalone version that works on any Mac, plus my vault original in `obsidian/` for reference.
