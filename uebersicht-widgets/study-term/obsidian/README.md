# STUDY//TERM — Obsidian edition (reference)

My own version. `LOG` appends a row to `00 — Meta/data/ledger.csv` in my vault, in my points-ledger format (15 Ð per 25-minute block, banked minutes, a one-line "output" note). It then runs `build.py` (not published), which regenerates every page that shows study hours, plus the wallet. The stats page reads the same model, including my 12-week-year targets.

`studyterm.py` here also handles the **75 Hard ticks** for `75hard/obsidian/75hard.jsx` (`tick <box>`).

Subjects are hard-coded to my university modules. Without the vault and build script, `LOG` fails. Use the [standalone edition](..) instead: same widget, its own CSV, pays the standalone wallet.
